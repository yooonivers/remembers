### 핵심부품
1. **메모리**
	1. 특징
		- 프로그램 실행하기 위해서, 메모리에 저장되어야 함
		- 실행되는 프로그램의 명령어와 데이터 저장
		- 저장된 값의 위치는 주소로 알 수 있음
	
2. **CPU**
	1. 특징
		- 메모리에 저장된 값을 읽고, 해석하고, 실행
		- 실행할 정보만 저장
	2. 대표 구성품
		- ALU : 계산기
		- 레지스터 : CPU 내부 저장장치
		- 제어장치 : 제어 신호(읽기/쓰기)를 내보내고, 명령어 해석하는 장치

3. **보조기억장치**
	1. 특징
		- 보관할 정보 저장
		- 메모리 보조하는 역할
	
4. **메인보드**
	1. 특징
		- 위에 언급된 핵심 부품들을 연결
		- 시스템 버스를 통해서 정보를 주고 받음
			종류 : 주소 / 데이터 / 제어 버스
