문자 집합과 인코딩
1. 문자 집합(Character set)
	1. 컴퓨터가 이해할 수 있는 문자의 모음
2. 인코딩(Encoding)
	1. 코드화하는 과정
	2. 문자 -> 0/1 기반의 문자 코드
3. 디코딩(Decoding)
	1. 코드 해석하는 과정
	2. 0/1 기반의 문자 코드 -> 문자

아스키 코드
1. 초장기 문자 집합 중 하나
2. 알파벳, 아라비아 숫자, 일부 특수 문자 및 제어
3. 7비트의 문자로 표현
4. 간단한 인코딩
5. 다른 언어 문자, 다양한 특수 문자 표현 불가

한글 인코딩
1. 완성형 (음절) / 조합형 (자음, 모음 따로)
2. 대표 인코딩
	1. EUC-KR
		- 완성형 인코딩
		- 2바이트 (16진수)
		- 여전히 모든 한글 표현에 부적합
3. 언어별로 인코딩하기에는 한계가 있음

유니코드
	1. 통일된 문자 집합(특수문자까지)
	2. UTF-8, UTF-16 등등
	3. UTF-8
		1. 유니코드 인코딩
		2. 가변길이
